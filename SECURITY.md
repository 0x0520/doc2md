# Security

doc2md parses untrusted documents. Crashes, hangs, excessive memory use or path
handling issues triggered by a crafted input are security bugs.

Please report them privately through
[GitHub security advisories](https://github.com/nullwerke/doc2md/security/advisories/new)
rather than in a public issue. You will get an answer within a week.

Only the latest release is supported; until the first release, the head of `main`.
